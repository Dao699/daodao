# 道 · 桌面宠物

Windows 桌面上的一只 AI 宠物「道」。它会听、会说、会动。

## 它能做什么

- **听得见**：Vosk 离线中文识别做唤醒与初听，接大模型（GLM）做理解与回答
- **说得出**：把回答合成中文语音（edge-tts），本地播放，不做字幕式播报
- **有表情**：12 张表情脸 + 8 帧走路 + 5 种姿势，按情绪和状态切换
- **有形象**：桌面立绘、场景背景（城市/海边/田野/花开/仙侠）、可挂的剑与披风
- **能上手机**：同一套形象做了随身版网页与 APK

## 目录

| 路径 | 内容 |
|---|---|
| `voice.py` | 语音对话主流程：录音、识别、调大模型、合成、播放 |
| `hear.py` | 听觉：录音、增益、归一化、VAD 断句、离线识别 |
| `trans.py` / `sing.py` | 翻译、唱歌两个小分支 |
| `voicefx.py` / `play_audio.py` | 音色与播放实现 |
| `src/桌面分身/` | 形象素材（表情脸、走位帧、姿势）与网页端 |
| `src/_apk/` | 手机随身版构建 |
| `icons/` | 桌面与 App 图标（多套轮换） |
| `tools/` | 开发与运维脚本 |
| `scene_*.png`、`props_*.png` | 场景与配件素材 |

## 运行环境

- Windows 10/11，Python 3.13
- 主要依赖：`vosk`、`miniaudio`、`sounddevice`、`edge-tts`、`Pillow`
- 离线识别模型 `vosk-model-cn` 体积较大，未随仓库分发
